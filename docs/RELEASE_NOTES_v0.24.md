# AlphaGENIE 0.24.0 — verified Brain9 research preview

Distribution and interface **0.24.0 / v0.24**; verified data presentation
**v0.24**; sealed scientific source **v0.20**; AlphaGenome SDK **0.8.0**.

## Changes

- Require a fresh inference epoch before starting real/null scoring; reject
  missing and legacy placeholder epochs before provider work begins.
- Include portable Frontal cortex comparison and fail-closed numerical checks
  for reference mismatches, dimensions, NaNs and infinities.
- Publish the recorded 19-context fresh-score reproduction and web/GitHub
  aggregation results with their precise scope and provenance.
- Synchronize the local and public v0.24 interface/data labels, export names and
  use notices. Preserve the sealed v0.20 artifact lineage and source dates.

## Verification evidence

The successful September 11 epoch freshly scored 19 contexts, each with 1,000
matched nulls. Fixed seed 20260527 regenerated the same designs. Web and GitHub
code separately aggregated the same fresh raw scores; no second independent
provider experiment is claimed.

Real raw scores, null medians, adjusted effects, consensus/P, the 17-variant
Brain9 matrix and both BH families reproduce the sealed values exactly.
Cosine differs from the sealed export by at most 2.22e-16. RBFOX1 16-kb and
PTCHD1 1-Mb Frontal cortex curves reproduce within file-serialization precision.
The provider checkpoint remains unresolved. See [verification details](VERIFICATION_v0.24.md)
and [validation records](VALIDATION.md).

## Privacy and use

Local installations use the user's own API key directly with Google DeepMind.
AlphaGENIE operators do not collect it. Optional key storage is owner-only
plaintext outside the repository. No login is required; use one trusted OS
account on a personal computer. Public website inference remains paused.

This remains a research preview. The existing code license and AlphaGenome
API/output terms are unchanged. No v0.18 data, private jobs, credentials or
reference genomes are included in the release.
